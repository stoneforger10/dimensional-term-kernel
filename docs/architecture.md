# Boundary and mechanism

The mechanism is exact rational **dimensional/affine typing**, not rewriting a
versioned graph or approving a claim. The two stored domains are immutable
source-derived unit environments and immutable exact-input calculation records.
Attempt and calculation keys use the native caller and deployment address;
source environments use the complete source-and-symbol input root. No owner can
change the interpretation after publication. No asset or credit is held.

The substantive GenLayer operation is independently interpreting source prose
into exponents, scales, offsets and point-versus-interval kinds. For example a
wrong SPAN factor doubles the observed speed, and confusing a HOT point with a
DELTA interval changes arithmetic validity. Shape or hash checks alone cannot
establish that those interpretations match the document. Each validator fetches
the full body and independently derives all fields before exact comparison.

After consensus the rational kernel executes without any LLM. That deterministic
part is not presented as the GenLayer innovation. It ensures semantic decisions
have exact, reusable consequences and cannot silently mix dimensions or origins.
Definitions are mathematical document semantics, not real-world measurements.

Stages: immutable source coordinate -> independent full-body acquisition ->
raw-byte hash binding -> independent complete semantic table -> exact consensus
-> READY/HELD environment -> exact type algebra -> optional bound calculation.

Malformed AI or distributed disagreement does not fabricate a successful state
or stored CONFLICTED result: consensus must first commit a report. HELD is an
agreed uncertainty/acquisition result, never a shorthand for disagreement.

Unknown definitions hold the whole environment rather than allowing a partially
usable coefficient set. Every input is examined only once per deployment, even
if held by a transient outage. This fail-closed availability tradeoff is explicit;
there is no administrator unlock or resampling method. Freshness means the exact
pinned definition revision, not a guarantee that it is current or authoritative.

Comparisons are in README. Shared web/signing scaffolding is reused intentionally;
the unit type algebra is not an auction, source classifier, monetary tariff,
policy Boolean table, graph mutation or service-delivery certificate.
